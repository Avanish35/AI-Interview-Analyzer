# 🤖 AI Interview Emotion & Confidence Analyzer

An AI-powered interview analysis system that evaluates a candidate's facial emotions during a mock interview using Computer Vision and Deep Learning. The application provides real-time emotion detection through a webcam and serves as the foundation for a complete AI interview assessment platform.

---

## 📌 Project Overview

The AI Interview Emotion & Confidence Analyzer is designed to assist candidates in improving their interview performance by analyzing facial emotions in real time.

The project utilizes Deep Learning models to recognize emotions from webcam input and displays the detected emotion during the interview. This project aims to evolve into a complete AI-based interview assistant with confidence scoring, speech analysis, interview feedback, and performance reports.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/avanish35/AI-Interview-Analyzer.git
```

### Navigate to Project

```bash
cd AI-Interview-Emotion-Analyzer
```

### Create Virtual Environment

```bash
python -m venv .venv
```

### Activate Environment

Windows

```bash
.venv\Scripts\activate
```

Linux / macOS

```bash
source .venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run Application

```bash
streamlit run app.py
```

---

## 🧠 How It Works

1. User enters their name.
2. Webcam captures live video.
3. Face Detection identifies the face.
4. DeepFace analyzes facial expressions.
5. Dominant emotion is displayed in real time.
